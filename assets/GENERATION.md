# BugKit logo

Generated with the built-in ImageGen tool on 2026-11-13. `bugkit-logo.png` is the original transparent raster output. Extension toolbar sizes and the Pages favicon are Lanczos-resized PNG derivatives; the mark was not redrawn. The original MIT project license is retained.

Prompt:

> Use case: logo-brand. Create ONE final professional logo symbol for BugKit, a developer tool for capturing precise bug reports and selected UI elements. Output a square transparent PNG with a single centered logo, generous transparent margin, no text, no wordmark, no mockup, no extra variants. Brand continuity: the existing BugKit identity uses coral (#ff4a6e) and warm orange (#ff7b3a); use these restrained accents with a strong dark ink silhouette that remains legible on both light and dark interfaces. Design a distinctive compact geometric beetle integrated with four focus/selection corner brackets: calm symmetry, clear negative space, bold simple shapes, immediately recognizable at 32px. Precise flat vector-like execution, careful optical balance, no thin lines, no tiny details, no eyes or cute mascot expression, no gradients, no shadows, no texture, no 3D, no glow. The icon should feel like a useful developer utility rather than promotional artwork. Transparent background is mandatory.

`extension-preview.png` is an actual Chromium screenshot of the extension on the bundled synthetic demo, produced by `scripts/browser-test.mjs`. The social preview combines the generated logo with factual product labels; its layout source is `social-preview.html`.
