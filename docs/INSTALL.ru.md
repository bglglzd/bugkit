# Установка BugKit

## Расширение Chrome

1. Скачайте **BugKit-MARK-1.1.0.zip** со страницы [релизов](https://github.com/bglglzd/bugkit/releases/latest).
2. Распакуйте ZIP в постоянную папку. Не удаляйте её после установки: Chrome читает расширение оттуда.
3. Откройте `chrome://extensions` и включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное**. Выберите папку **extension**, внутри которой лежит `manifest.json`.
5. Откройте обычный сайт. Нажмите значок BugKit MARK или **Ctrl+Shift+Y**. На macOS — **⌘+Shift+Y**. Закрепить значок можно через меню расширений Chrome.
6. Нажмите **Выбрать элемент**, отметьте нужное место и опишите проблему. Откройте **Проверить текст отчёта**, затем скопируйте текст или сохраните Markdown/JSON. Снимок добавляется отдельно, по вашему нажатию.

Git, Node.js, аккаунт и ключи API не нужны. Сочетание меняется на `chrome://extensions/shortcuts`. Для локальных HTML-файлов включите **Разрешить открывать локальные файлы** в настройках расширения.

### Обновление

Закройте панель MARK, замените файлы в той же папке файлами нового релиза, нажмите **Обновить** на карточке расширения в `chrome://extensions` и перезагрузите вкладку сайта. Для ZIP-установки автоматического обновления нет. Выбирайте именно `extension`, а не корень репозитория.

### Если что-то не работает

| Симптом | Что сделать |
|---|---|
| Chrome не видит манифест | Распаковать ZIP и выбрать вложенную папку `extension` |
| Горячая клавиша занята | Нажать значок или назначить другое сочетание |
| Панель не открывается | Проверить на обычном `https://` сайте: служебные страницы и магазин защищены |
| После обновления панель выдаёт ошибку | Обновить расширение и перезагрузить вкладку сайта |
| Нет версии сайта | Указать её в «Детали и версия»: сайт может не публиковать метаданные |
| После перезагрузки нет снимка | Добавить заново: в черновике сохраняются текст и элементы |

Отчёты никуда не отправляются автоматически. Черновики привязаны к вкладке и адресу; при закрытии вкладки или сеанса они удаляются. Расширение не узнаёт о выходе из аккаунта сайта: перед сменой пользователя очистите черновик. Перед передачей проверьте текст, путь страницы и снимок: они могут содержать личные данные.

## Встроить BugKit в приложение

Агент добавляет форму, хранилище, админку и статусы в код вашего проекта. Расширение для этого не требуется.

Для Claude Code выполните по очереди:

```text
/plugin marketplace add bglglzd/bugkit
/plugin install bugkit@bugkit
/bugkit:install
```

Другому агенту передайте:

```text
Внедри BugKit в этот проект по https://raw.githubusercontent.com/bglglzd/bugkit/main/INSTALL.md
```

Установщик должен прочитать [контракт](../SPEC.md), [рецепт](../recipes/) и [требования к надёжности](../HARDENING.md). Готовность означает проверенный путь «отправка → сохранение → разбор → закрытие → ответ автору», включая восстановление после ошибки. Рецепты не являются готовым сервером для любого приложения.
