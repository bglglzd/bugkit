Install in Chrome

Инструкция на русском ↗
  1. Extract the release ZIP

    Download BugKit-MARK-1.1.0.zip and keep its extracted folder in a permanent location.

  2. Load the extension folder

    Open chrome://extensions, enable Developer mode and choose Load unpacked. Select extension, which contains manifest.json.

  3. Open a website and invoke MARK

    Click its toolbar icon, or press Ctrl+Shift+Y (macOS: ⌘+Shift+Y). Select an element, add a description and review the export.

No Node.js, Git, account or API key is needed. Change shortcuts at chrome://extensions/shortcuts. To update, replace the files, reload the extension and reload the website tab. ZIP installs have no automatic updates.

Scope and privacy

Local extension

Captures explicitly selected elements and optional visible screenshots. Exports Markdown, JSON and PNG. Draft text survives page reloads within the tab's browser session.

No automatic collection of form values, full HTML, console history or network traffic. It does not send reports to a server or fix bugs.

Review before sharing

URL queries, fragments and credentials are stripped. Paths, visible text, identifiers and screenshots may still disclose private data. Clear drafts when changing website accounts.

Internal Chrome pages and some viewers block extensions. Iframe contents and closed Shadow DOM are not inspected. Physical macOS setup and native keyboard dispatch need manual verification.
